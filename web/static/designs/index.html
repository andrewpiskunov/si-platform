Три характера.
Одна игра.

В каждом варианте есть каталог, игровая комната и редактор. Это интерактивные HTML-макеты: поиск и открытие вопроса работают на демонстрационных данных. Настоящий сервис — по ссылке внизу.

Клуб

Тёплая бумага, крупная антиква, зелёный акцент. Каталог как редакционная подборка. Мой выбор для открытого сообщества.

Табло

Тёмный зал, янтарные цифры, строгая сетка. Игра на первом плане. Подходит для вечерних сессий и трансляций.

Картотека

Холодный светлый фон, синяя навигация, плотные списки. Практичный инструмент для авторов и большой библиотеки.
