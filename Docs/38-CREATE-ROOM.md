# Создание комнаты — 23 октября 2026

Согласованный сценарий: отдельное окно из списка комнат; поиск и выбор пакета, затем настройки и переход в лобби. Из карточки пакета открывается то же окно с выбранным пакетом. Вместо отдельной страницы переиспользуется форма CreateRoom в нативном dialog — так настройки и обработка серверных ошибок остаются общими с мастерской.

Реализация:
- Кнопка «Создать комнату» в заголовке списка и его пустом состоянии.
- Поиск опубликованных пакетов, страницы по 50 результатов, число вопросов и раундов, автор. Ошибка загрузки и повторная попытка. Длительность не отображается: достоверной оценки в данных нет.
- Встроенный демонстрационный пакет выбирается явно; без выбора отправка недоступна.
- Название, имя ведущего, оформление, доступ, готовность игроков, голосовая ссылка, правила и таймеры.
- Нативный захват фокуса, Escape, возврат фокуса, блокировка закрытия при отправке. На телефоне колонки располагаются друг под другом.
- После входа доступны только разрешённые внутренние возвраты: создание из списка или карточка пакета с create=1.

Ограничения сервера: вместимость фиксирована — 12 игроков и 20 зрителей. Настраиваемое число мест и запрет зрителей пока не реализованы. Поиск охватывает публичный каталог; свои черновики по-прежнему запускаются из редактора.

Проверка: e2e/create-room-dialog.mjs проверяет поиск, выбор, доступ, блокировку отправки без пакета, payload с ID и ревизией, серверную ошибку, реальное создание демонстрационной комнаты, переход в лобби, адаптивность и фокус. Временный аккаунт удаляется после проверки. e2e/catalogue-navigation.mjs обновлён для новой точки входа. Svelte check и production build.
