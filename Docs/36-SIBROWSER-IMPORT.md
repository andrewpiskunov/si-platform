# Парсинг SI Browser и добавление в наш каталог

Статус: **в работе: сборщик метаданных готов; скачивание одного SIQ технически проверено, автоматический загрузчик ещё не реализован**, запрос пользователя от 23.10.2026. Связь: FR-20, существующий импортёр `cmd/catalogue-import`, Docs/26.

Источник: https://www.sibrowser.ru/ . Цель — добавить в наш каталог пакеты и метаданные SI Browser с сохранением авторства и происхождения. Это новая задача на адаптер источника; существующий локальный CLI не является готовым парсером сайта.

- [x] Реализовать ограничение частоты, повторы, контрольную точку и журнал ошибок.

- [x] По указанию пользователя проверить обычную ссылку одного SIQ: цепочка SI Browser → VK → CDN работает без авторизации; прочитано 8 КБ.
- [ ] Реализовать загрузчик архивов; отдельно определить основание публикации. Директива robots не является технической HTTP-блокировкой.

## Приёмка

Пилотные пакеты находятся в каталоге через поиск, содержат корректные метаданные и источник, открываются в карточке и запускаются в комнате в пределах поддержанного профиля SIQ. Повтор импорта не создаёт копии, сбой не требует перезапуска всей партии. Неподдержанные элементы видны в диагностике.

23.10.2026 парсер проверен на публичной главной странице. Подробности реализации, проверок и оставшихся ограничений ниже; массовое скачивание не выполнялось.

## Реализация адаптера — 23.10.2026

Статус: **адаптер метаданных и подготовки локальной партии реализован; внешний импорт и публикация ожидают разрешённый канал SIQ и основания прав**.

Проверенные публичные точки:

- `https://www.sibrowser.ru/`: серверный HTML, microdata Article/Person, ссылки карточек `/packages/ID`, пагинация `rel=next` → `/?page=2`. Публичный документированный JSON API/экспорт на исследованной странице не обнаружен; адаптер не опирается на недокументированный API.
- `https://www.sibrowser.ru/robots.txt`: `User-agent: *`, `Disallow: */direct_download`. Автоматический загрузчик SIQ через этот маршрут **не реализован**; `direct_play` для обхода не используется.
- На главной есть ссылки на автора сайта и VK, но нет предоставляющей право перепубликации лицензии. Это ограниченный результат исследования главной, а не юридический вывод обо всём сайте. robots регулирует обход, не права на содержание.

### Команды

Python 3.10+, без сторонних зависимостей:

```sh
# Только метаданные; по умолчанию одна страница, без скачивания/публикации SIQ.
python3 scripts/sibrowser_import.py collect --output ./.local/sibrowser --pages 1
# Повтор продолжает со следующей сохранённой страницы.
python3 scripts/sibrowser_import.py collect --output ./.local/sibrowser --pages 1
```

`state.json` сохраняет записи по внешнему ID и следующую страницу атомарно; `events.jsonl` — успешные страницы и безопасные классы ошибок; `robots.txt` — снимок политики. На каждом запуске политика обновляется, при недоступности robots обход не начинается. Минимум 2 секунды между запросами, учитывается Crawl-delay; максимум 3 попытки на временную сетевую ошибку/429/5xx. Длинный Retry-After останавливает запуск. Редиректы и любые URL вне корня пагинации/карточек/robots запрещены. Страницы ограничены 4 MiB, партия — 100 страниц; обычный пилот — одна. Запускайте один процесс на каталог результата.

Сохраняются название, автор, исходный ID/URL, дата, описание, теги, отображаемый размер, число вопросов, текст раундов/тем, проценты медиа и категорий. Текст тем сохраняется как текст: запятая внутри названия не превращается в ложную новую тему. Проценты и размер остаются сведениями источника; точный размер и структура игрового пакета проверяются из разрешённого SIQ обычным импортёром. `rights_status=unverified` не меняется автоматически.

### Мост к существующему импортёру

После получения разрешённых файлов положить SIQ в каталог будущего манифеста. В `approvals.json` оператор явно связывает выбранные внешние ID с этими файлами и фактическим основанием:

```json
{"items":[{"external_id":"ID_ИЗ_STATE","file":"authorized.siq","license":"ФАКТИЧЕСКАЯ ЛИЦЕНЗИЯ","permission_basis":"Ссылка/номер согласования","attribution":"Автор, при необходимости уточнение"}]}
```

```sh
python3 scripts/sibrowser_import.py manifest --state ./.local/sibrowser/state.json --approvals ./pilot/approvals.json --output ./pilot/manifest.json
go run ./cmd/catalogue-import -manifest ./pilot/manifest.json -check
# Затем обычный импорт с SI_API_URL/SI_API_TOKEN из Docs/26:
go run ./cmd/catalogue-import -manifest ./pilot/manifest.json
```

Адаптер требует непустые license/permission_basis, известный ID, локальный обычный SIQ внутри каталога, не более 250 MiB; вычисляет SHA-256 и отклоняет повтор ID/хеша внутри партии. Это не автоматическая проверка достоверности операторского основания. Namespace — `sibrowser.ru`. Автор и ссылка передаются в существующую модель прав, дополнительные HTML-метаданные остаются в sidecar `state.json`; содержание каталога строится по SIQ. Результат обычного импорта — приватный черновик с неподтверждёнными правами; публичный каталог требует стандартной модерации.

Повторы одного источника/ID защищены серверными receipt; смена файла/метаданных под прежним ключом даёт конфликт, а не тихую замену. Хеш-дедупликация адаптера действует внутри одной партии, глобального объединения разных внешних ID пока нет. Удаление и изменение на источнике не удаляют и не переписывают опубликованные пакеты. Для повторного обзора метаданных используется новый каталог состояния; постраничная выдача не является снимком, поэтому новые поступления могут сдвинуть страницы. Полная периодическая синхронизация/сверка удалений — отдельный незавершённый этап.

## Проверка обычной ссылки скачивания — 23.10.2026

По отдельному указанию пользователя проверен один пакет: https://www.sibrowser.ru/packages/25928 . HEAD и GET `/packages/25928/direct_download` отвечают HTTP 302 и направляют на документ VK. VK отвечает 302 на CDN `psv4.userapi.com`, CDN отвечает HTTP 206 на Range bytes=0-8191. Прочитано 8192 байта, сигнатура ZIP `PK` присутствует, полный размер из Content-Range — 10 638 396 байт. Полный архив не скачан и не импортирован.

Запросы выполнены без аккаунта, Authorization и Cookie; cookie, выданная VK, не сохранялась и не отправлялась дальше. Для этой конкретной ссылки авторизация, CAPTCHA и cookie не потребовались. Это подтверждает техническую доступность файла, но не доступность всего каталога и не права перепубликации. Временный подписанный URL CDN не сохраняется как постоянный источник. robots.txt остаётся декларацией для обходчиков, а не HTTP-блокировкой. Существующий адаптер пока по-прежнему ограничен метаданными; загрузчик архивов требует отдельной реализации.

## Продолжение в другой сессии

Сначала прочитать этот документ и `Docs/26-CATALOGUE-IMPORT.md`. Репозиторий: `si-platform`, ветка на момент сохранения — `main`. Коммит парсинга отделён от незакоммиченной работы над интерфейсом; эти изменения не сбрасывать и не включать случайно в правки импортёра.

Быстрый запуск сборщика из корня (Python 3.10+, зависимости не нужны, API и БД для collect не нужны):

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s scripts/tests -p 'test_sibrowser_import.py' -v
python3 scripts/sibrowser_import.py collect --output .local/sibrowser --pages 1
```

Следующий запуск той же команды продолжит со следующей страницы. Для нового обзора с первой страницы используйте новый каталог output. Результаты пилота в `/tmp` временные, в Git не включены и для запуска не нужны.

Следующий технический этап: реализовать отдельный загрузчик SIQ по обычной ссылке (не путать с существующим metadata-only collect). Обрабатывать цепочку редиректов SI Browser → VK → CDN, проверять каждый адрес, ограничивать размер и время, сохранять файл атомарно, проверять ZIP/SIQ и SHA-256, поддержать повтор без дубликатов и понятный отчёт. Не хранить временный подписанный CDN URL как постоянный идентификатор источника. Сначала небольшой пилот, затем передача манифеста существующему `cmd/catalogue-import`. Текущие safe_url/NoRedirect сознательно допускают только метаданные: менять их поведение для скачивания без отдельного режима не следует.
