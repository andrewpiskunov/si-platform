# SIQ: спецификация и план реализации

> Исполнение: `superpowers:executing-plans`, самостоятельно по задачам; одно независимое ревью этапа. Пользователь поручил полную реализацию без остановки на повторном согласовании требований.

**Goal:** дать игре и редактору общую модель SIQ v4/v5, безопасный импорт, отчёт и экспорт v5 без молчаливой потери поддержанных данных.
**Architecture:** `internal/packs` — модель/валидация; `internal/siq` — ограниченный ZIP/XML-конвертер; файлы читаются потоково, XML ограничен 10 MiB. Сетевое хранение и HTTP будут подключены следующим этапом.
**Tech Stack:** Go 1.27.3, archive/zip, encoding/xml, x/text/unicode/norm; без исполнения внешних сценариев.
**Spec:** Docs/02-REQUIREMENTS.md FR-03/11/18, профиль P0, Docs/03-ARCHITECTURE.md §6.

## Контракт

В модели сохраняются метаданные пакета/раунда/темы/вопроса, авторы, источники, комментарии, верные/неверные ответы, типы/параметры и порядок контента. Параметры SIQ v5 сохраняют вложенность, числовые множества, размещение и длительность медиа. У вопросов есть стабильный ID для дальнейшего редактирования; ID при первоначальном импорте определяется положением.

V4 scenario разделяется marker на question/answer; voice преобразуется в audio, say сохраняется как текст ведущего. Обычные и специальные типы распознаются; игровая поддержка спецвопросов появится на этапе правил. Пустые поля, неизвестные типы/параметры, произвольный script, HTML, неизвестная версия, отсутствующие/внешние медиа получают диагностическое сообщение с путём. Нельзя объявлять пакет пригодным, если есть блокирующее сообщение. Оригинал не меняется; экспорт неподдержанного документа отклоняется с отчётом.

Импорт не загружает URL. Не извлекает файлы по предоставленным путям. Проверяет размеры до и во время чтения, CRC, нормализацию имён и конфликты. Отчёт различает предупреждения и блокировки. Export пишет content.xml v5 и исходные медиа потоком, проверяется повторным импортом.

## Global Constraints

- Оригинал ≤250 MiB, распаковка ≤1 GiB / 5 000 файлов; XML ≤10 MiB, до 2 000 вопросов, медиа ≤100 MiB.
- До 64 уровней XML и 200 000 XML-узлов; запрет DTD, произвольных processing instructions и XML внешних сущностей.
- ZIP64/многотомные архивы вне лимитов этого этапа отклоняются явно; central directory ограничивается до разбора.
- Запрещены абсолютные пути, `..`, обратный слеш, симлинки, неоднозначные Unicode/URL-кодированные имена и вложенные архивы.
- Правильные ответы и комментарии остаются в приватной модели; публичную проекцию определит игровой модуль.
- Обработка отменяется context; большие файлы не загружаются целиком в память.

## Review Focus

- ZIP с ложным размером/CRC и взрывным сжатием не обходит лимиты.
- Два разных имени после декодирования/Unicode-нормализации не подменяют файл.
- Неизвестный XML, тип/параметр или script не исчезает молча при экспорте.
- Граница вопрос/ответ и комментарии ведущему сохраняются при v4→v5.
- Медиа после экспорта совпадают побайтно; внешние ссылки не вызывают сетевых запросов.
