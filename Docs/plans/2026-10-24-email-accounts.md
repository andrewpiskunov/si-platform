# Регистрация по почте

Согласовано: почта для входа, публичное имя на любом языке, пароль с подтверждением. Старые логины продолжают работать. Подтверждение адреса и восстановление пароля входят в переход.

Архитектура: отдельные одноразовые заявки, только хеш токена в БД; аккаунт создаётся после подтверждения. Email не включается в публичную User-проекцию. SMTP для доставки; явный локальный файловый транспорт для разработки. Письма не отправляются реальным адресатам в тестах.

- [x] Миграция, регистрация/подтверждение, вход по почте и старому логину.
- [x] Сброс пароля, срок/одноразовость ссылок, отзыв сессий.
- [x] Почтовый транспорт и конфигурация локального запуска.
- [x] Формы почты, Unicode-имени, подтверждения и восстановления.
- [x] Проверки БД, браузера и инструкция запуска.

Проверки: неизвестные адреса не раскрывают наличие аккаунта; повторная/просроченная ссылка отклоняется; старые сессии недействительны после сброса; имя на кириллице/арабском/японском сохраняется; локальные письма доступны только через файловую систему.


Результат: миграция 00021, сервис email.go, SMTP/локальный mail.go, HTTP-маршруты подтверждения и восстановления, форма с пятью состояниями. В БД только хеши ссылок; ссылки удаляются после использования, смены пароля и удаления аккаунта. Выдача писем ограничена на адрес и через существующий IP rate limiter. Email не входит в публичный User. Реальная SMTP-доставка не проверялась — для приёмки использован файловый транспорт.

Проверки: `go test ./internal/accounts ./internal/server ./cmd/server` с TEST_DATABASE_URL (временные схемы, не пропущены), Svelte check и production build, `e2e/email-accounts.mjs`. В браузере выявлен и исправлен сброс состояния формы при смене sessionEpoch после восстановления. Локальный сервер перезапущен на 5175/8082 с новой миграцией; другая копия на 5174 не менялась.
