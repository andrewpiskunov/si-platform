# Перенос «Эфира» в приложение

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Применить согласованный «Эфир» к действующему Svelte-приложению без потери тем и игровых функций.
**Architecture:** Глобальные токены и отдельный слой broadcast.css; переиспользуемые Avatar и Icon; существующие серверные состояния и контракты без изменений.
**Tech Stack:** Svelte 5, CSS custom properties, локальный Golos, существующий Go API.

- [x] 1. Оболочка и каталог: шрифт и ресурсы вне mock paths, навигация, карточки, формы; сохранить фильтры, ссылки и состояния ошибок. Проверка check/build и браузер каталога/редактора.
- [x] 2. Игра: портреты по стабильному ID, карточки реальных участников/ведущего, сетка табло и цифры, адаптивность. Проверка браузерного smoke с 12 участниками.
- [x] 3. Совместимость: builtin classic остаётся ID; подпись «Эфир», custom не получает жёсткие цвета/шрифт. Проверка theme-regressions и themes; полный web test/check/build.
- [x] 4. Один независимый обзор всего этапа, один проход важных исправлений; документация и commit.

**Review focus:** CSS specificity для пользовательских светлых тем; отличие базового и custom табло; стабильность аватаров и приватность; длинные имена/12 участников; доступность ссылок и скрытые состояния; отсутствие изменения игровых событий/готовности/правил.

**Ruling:** выбранный дизайн и просьба применить его — разрешение на реализацию, дополнительное согласование оформления не требуется. Предыдущий незавершённый этап метрик не включается в этот обзор.
