# Скачивания, оценки и лайки пакетов

Согласовано в диалоге 23 октября 2026: три независимых показателя в публичном каталоге и карточке. Синк остаётся остановленным.

## Поведение
- Скачивания: значение источника плюс успешные полные выдачи SIQ через публичный download endpoint. Экспорт черновика и работа парсера не учитываются. HEAD, Range, ошибки и оборванные передачи не увеличивают счётчик. Это число передач, а не уникальных людей.
- Оценка: целое 1–5, одна на аккаунт, можно изменить или удалить. Лайк независим: один на аккаунт, можно снять. Изменения доступны только активным пользовательским сессиям, с существующей защитой Origin/CSRF.
- Публичные суммы не раскрывают личности проголосовавших; собственное состояние доступно отдельным приватным запросом. Удалённые аккаунты исключаются из голосов.
- Исходные значения хранятся отдельно от локальных. Повторный импорт заменяет снимок источника; не прибавляет его повторно и не изменяет локальные голоса/скачивания.
- Среднюю оценку объединяем по числу голосов: (sourceAverage*sourceCount + localSum)/(sourceCount+localCount). Без количества исходных оценок отображаем две оценки с явными подписями. Отсутствующие исходные показатели — null, не нули. Локальный пакет начинает с 0 скачиваний, 0 лайков и без оценок.
- Снятые с публикации, заблокированные и удалённые пакеты не раскрывают показатели и не принимают голоса.

## Подход
Выбран отдельный снимок источника плюс локальные события/голоса. Общий изменяемый счётчик терял бы происхождение и дублировал импорт; полностью раздельное отображение не выполняло бы требование общего числа скачиваний. Оценки агрегируются только при совместимой шкале 1–5.

## Импорт
Downloads уже присутствует. Добавить nullable rating, rating_count, likes. Читать только явную разметку соответствующего пакета, не рекомендации. На проверенных страницах рейтинг/лайки не обнаружены: не придумывать значения и не выдавать синтетический тест разметки за подтверждение живого источника. Поддержать стандартную microdata AggregateRating со шкалой 1–5; неизвестная шкала остаётся неподдержанной. Не запускать синк без нового запроса пользователя.

## Реализация и проверка
PostgreSQL: счётчик скачиваний и голоса (pack,user) с FK. Go: агрегаты в публичных Card, session-only API голосования, подсчёт успешных download. Svelte: компактные три показателя и доступные кнопки оценки/лайка на странице пакета. Экспорт персональных данных включает собственные голоса. Проверить конкурентные повторные действия, публикационные ограничения, повторный импорт, null, формулу веса, отозванные сессии, частичные/ошибочные скачивания и мобильную вёрстку.
