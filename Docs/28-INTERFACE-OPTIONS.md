# Варианты интерфейса для выбора

Открыть: http://localhost:5173/designs/index.html

Запрос: выразительный, удобный интерфейс сообщества без шаблонного оформления. Пока выбираем направление; HTML-макеты не заменяют основной интерфейс.

| Вариант | Характер | Сильная сторона | Компромисс |
|---|---|---|---|
| Клуб | Бумажный фон, антиква, тёмно-зелёный акцент | Приглашает играть, подходит редакционным подборкам | Меньше пакетов на одном экране |
| Табло | Тёмный фон, янтарные цифры, широкая сетка | Атмосфера игровой комнаты, контрастное табло | Длинные тексты удобнее читать в светлой теме |
| Картотека | Светлая рабочая среда, синий акцент, строки | Быстрый просмотр большой библиотеки | Более утилитарный характер |

Рекомендация: «Клуб» для общего сайта; при выборе можно перенести плотный список из «Картотеки» и игровой экран из «Табло».

В каждом варианте три переключаемых экрана: каталог, игровая комната, редактор. Поиск, фильтры, пример вопроса и локальная проверка заполнения работают. Публикация, приглашения и сохранение не подключены; это явно обозначено. Все вопросы табло открывают один демонстрационный пример. Остальные названия пакетов — иллюстрации оформления.

Проверены Playwright: три варианта, поиск, показ ответа, редактор, отсутствие переполнения на 390 px; ошибок JavaScript нет. Макеты используют локальные системные шрифты и не запрашивают внешние ресурсы.

## Постоянный тестовый пакет

В локальный каталог опубликована «Разминка перед игрой»: один раунд, четыре темы, 20 текстовых вопросов. Пакет проходит обычные API создания, публикации и модерации. Публичный каталог и отображение карточки проверены в браузере. Внешние пакеты не копировались.

Повторное заполнение локального preview: `node scripts/seed-preview.mjs` из корня проекта, с настроенными Go/Node и `DATABASE_URL` локального preview. Скрипт требует зависимости `e2e`, оставляет демоаккаунт и пакет, не выводит пароль; после модерации возвращает аккаунту роль автора. Повторный запуск пропускает уже опубликованный пакет с тем же названием. Не использовать тестовую БД или production.

## Итерация 2: «Синяя студия»

Первые три направления отклонены пользователем. Новый ориентир — узнаваемая палитра и устройство оригинальной телевизионной «Своей игры» в современном веб-интерфейсе.

Открыть: http://localhost:5173/designs/studio.html

Референсы: [кадры студии и табло](https://www.starhit.ru/novosti/novaya-studiya-vozvrashenie-vassermana-kuleshov-raskryl-kakie-syurprizy-zhdat-k-30-letiyu-shou-svoya-igra-5603876/), [студия и стойки игроков](https://www.nntu.ru/news/detail/zhizn-v-ngtu/vse-novosti/prepodavatel-ngtu-pobedil-v-teleshou-svoya-igra). Фотографии в макете не используются.

Основные решения: кобальтовые ячейки, золотые цифры с засечками, тёмно-синий фон, счёт игроков в отдельных стойках; спокойная боковая навигация и компактные инструменты. Палитра «Классика» насыщенная, «Вечер» приглушённая. Начальный экран — игровое табло, а не рекламная страница.

Три экрана: игровая комната, каталог, мастерская. Все 20 вопросов имеют отдельные тексты и ответы; после показа ответа ячейка отмечается просмотренной. Правки редактора живут до перезагрузки страницы и доступны в предпросмотре. Реальные подключения, счёт и приглашения не симулируются как работающий сервис: это макет выбора дизайна.

Проверено в Chromium через Playwright: разные вопросы и ответы, просмотренные ячейки, переключение палитры, поиск, предпросмотр правок и сохранение их при выборе другого вопроса. На ширинах 390, 768 и 1024 px три экрана не переполняют окно. Ошибок JavaScript нет. Десктопный и мобильный скриншоты просмотрены.
