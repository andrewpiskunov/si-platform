## Что не переносится через Git

БД, скачанные SIQ/медиа, Docker volumes/images, зависимости и секреты не являются содержимым ветки. Без отдельного переноса запуск на новой машине создаст пустую БД и не восстановит каталог/checkpoint.

На исходной машине:
- PostgreSQL: контейнер `si-platform-local-db`, база `si`, пользователь `si`, порт хоста 55432.
- API: `si-platform-sibrowser-api`, образ `si-platform-engagement:local`, порт 8081.
- Object storage и данные API: bind mount `/Users/andrew/Documents/Personal-Super-Agent-Ru/Docs/Programs/si-platform/.local/data` → `/data`.
- Фронтенд текущей ветки: localhost:5174.
- Full worker: `si-platform-sibrowser-full`, создан, но не запущен.
- Приватное окружение: `.local/sibrowser/sync.env`; локальные операционные заметки: `.local/sibrowser/RUN.txt`. Не добавлять токены/пароли в Git. На новой машине обновить адреса API/БД и при необходимости выпустить новый токен для существующего владельца источника.

Чтобы перенести именно текущий каталог, сделать согласованную копию БД и `/data`: остановить пишущие API/worker-процессы, сохранить PostgreSQL через `pg_dump -Fc`, скопировать весь каталог данных, затем возобновить API на исходной машине. Full оставить остановленным. Дамп содержит приватные данные аккаунтов: переносить защищённым каналом вне Git. На новой машине восстановить дамп в отдельную БД через `pg_restore`, подключить скопированные данные к `/data`, применить миграции и запустить один API. Не подключать одновременно два API к одной рабочей БД.

Этот документ фиксирует процедуру; резервная копия и перенос БД/медиа автоматически не выполнялись.
