# «Эфир» — основное оформление приложения

Пользователь выбрал «Эфир» для основного приложения 21.10.2026 и подтвердил, что готовые и пользовательские темы должны оставаться сменяемыми. Основа — refined/broadcast.html с аватарами и цифрами Golos без засечек.

Переносим в Svelte: верхнюю навигацию, палитру, типографику, каталог без рекламного hero, оформление форм/мастерской, синее табло, карточки участников и ведущего. Вместо демонстрационных имён/счёта используются существующие игровые данные. Встроенные портреты назначаются стабильно по ID без предположений о поле человека; пользовательской загрузки аватара на этом этапе нет.

Совместимость: внутренний builtin classic сохраняется в API/снимках, в UI называется «Эфир». Базовая оболочка использует новую палитру; пиратская/аниме и пользовательские manifest продолжают переопределять переменные. Синие цвета табло задаются только для базового/ classic оформления. Пользовательские цвет, шрифт, геометрия и локальные предпочтения остаются приоритетными. API/правила/жизненный цикл комнаты не меняются.

Проверяем основной каталог, вход, редактор, настоящую комнату с 12 участниками, мобильные размеры, собственную светлую тему, возврат к базовой и сбой оформления. Публичные заявления о полном покрытии настроек SIGame не добавляются.

## Реализация и приёмка

«Эфир» применяется к основному приложению по адресу http://localhost:5173/ (не только к HTML-макету). Каталог, оболочка, формы и мастерская используют локальный Golos и общую палитру; классическое табло — кобальтовое с золотыми цифрами без засечек. Участники и ведущий получают стабильные встроенные портреты. Название в выборе оформления — «Эфир», сохранённый идентификатор — `classic`.

Проверены 103 web unit-теста, Svelte check без ошибок/предупреждений и production build; браузерная цепочка регистрация → редактор → SIQ → комната с 12 участниками → ответ → восстановление счёта → завершение. Также проверены собственная тема, переключение на паузе, личные предпочтения, отзыв оформления, медленный/сломанный декор, контраст двух светлых палитр и повтор загрузки табло.

Независимый обзор выявил один важный конфликт планшетных breakpoint: карточки игроков сжимались на 951–1000 px. Добавлена регрессия с длинным именем (RED→GREEN), переход списка согласован с основной сеткой. Отдельный браузерный тест воспроизвёл наследование синего цвета вложенным предпросмотром; базовые цвета исключены из custom-preview (RED→GREEN).

Проверка переключения тем обнаружила существующую гонку: применение было доступно до загрузки версии выбранной темы. Теперь ThemeChooser сообщает состояние загрузки, а создание комнаты и применение ждут её завершения. Регрессия удерживает ответ сервера и проверяет недоступность применения (RED→GREEN); полный сценарий смены тем прошёл после исправления.

Ограничения: встроенные портреты — иллюстрации, выбор может повторяться; загрузка пользовательских фотографий не реализована этим этапом. Полный набор экранов и настроек из разбора SIGame не входит в перенос оформления. Готовые и пользовательские темы сохраняют собственные цвета, шрифт и геометрию.
