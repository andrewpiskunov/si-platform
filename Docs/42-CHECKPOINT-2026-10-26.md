## На другой машине

```sh
git fetch origin
git switch --track origin/feat/sigame-game-experience
# Если локальная ветка уже существует: git switch feat/sigame-game-experience
# Затем git pull --ff-only
npm --prefix web ci
```

Требуются Node ≥22.17, версия Go из `go.mod` и PostgreSQL. Создайте локальную БД и задайте её собственный DATABASE_URL:

```sh
DATABASE_URL='postgres://USER:PASSWORD@127.0.0.1:5432/DATABASE?sslmode=disable' \
DATA_DIR=.local/data ./scripts/dev-local.sh
```

Скрипт применит миграции и запустит web на http://localhost:5175, API на 8082. Карта: `/product-map.html`, аудит: `/sigame-audit.html`. Действующий запуск требует свободных портов. Подробности окружения и локальной почты — в [README](../README.md).

Git не переносит текущую PostgreSQL-базу (аккаунты, комнаты, черновики), `.local/data`, `.local/mail`, `.env`, node_modules и временные отчёты. На чистой машине создайте аккаунт и используйте демонстрационный пакет. Чтобы перенести именно существующие комнаты/пользователей/загруженные файлы, нужен отдельный перенос БД и каталога данных.

Не откатывать предыдущие изменения ради продолжения: следующий этап выполняется поверх этого checkpoint. Пользователь предпочитает разделение независимой реализации и проверок между субагентами.
