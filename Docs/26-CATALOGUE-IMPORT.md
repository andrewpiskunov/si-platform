# Разрешённый импорт каталога

Цель FR-20 — воспроизводимо загрузить согласованную партию SIQ, сохранить источник и основание разрешения, безопасно повторить запуск. Массовое копирование SI Browser не включается автоматически: ссылка на автора сама по себе не является разрешением. Реальный внешний пилот зависит от согласованной партии; локальная приёмка использует собственные тестовые пакеты.

## Как работает

Оператор с ролью admin запускает CLI на Linux/Unix с JSON-манифестом и локальными SIQ. Токен берётся из переменной окружения, требуется drafts:write. Сервер не скачивает указанные ссылки. CLI передаёт архивы существующему ограниченному загрузчику; обработка медиа, квоты и диагностика остаются общими с обычным импортом.

На каждый файл манифест содержит namespace, external_id, file, sha256, source_url, license, attribution, permission_basis. Последнее — краткая ссылка/номер согласования или описание собственной лицензии, без секретов и персональной переписки. URL источника только HTTP(S), без учётных данных. Ограничение партии — 100 файлов, JSON — 1 MiB; архив — 250 MiB. Локальный путь разрешается внутри каталога манифеста через os.Root. Никаких URL загрузки, обхода сайтов или редиректов с токеном.

Сервер сохраняет независимую запись (владелец, namespace, external_id), контрольную сумму и метаданные до приёма файлов, в одной транзакции с созданием загрузки. Совпадающий повтор возвращает прежнюю загрузку/пакет; изменение содержимого или метаданных под тем же ключом — конфликт. Результат привязывается к записи в транзакции создания черновика. Удалённый, заблокированный или физически очищенный пакет не восстанавливается повтором. Лимит записей — 100000 на владельца.

CLI возобновляет незавершённую загрузку с серверного offset, ждёт обработку и выдаёт компактный JSON-отчёт. Неопределённый сетевой исход проверяется повторным запуском того же манифеста. Терминальная ошибка обработки сохраняется; автоматического повторного создания нет. После разбора причины оператор оформляет отдельную исправленную запись с новым external_id. Отчёт включает исходный ключ, upload_id, draft_id, статус и безопасный код ошибки.

Результат — приватный черновик. Лицензия, ссылка и атрибуция предварительно заполнены, подтверждение публикации остаётся выключенным. Для выхода в каталог нужны обычные подтверждение прав и модерация. Роль администратора перепроверяется при создании задания и перед сохранением пакета; потеря роли/отзыв токена останавливают импорт.

## Приватность и проверка

Записи доступны только своему владельцу через авторизованный API и экспорт данных; доказательство разрешения не публикуется. Для живого аккаунта запись сохраняется после удаления пакета ради защиты от повторного создания. После удаления аккаунта очищается через 30 дней ограниченными партиями с учётом аренды экспорта. Архивы удаляются по общим правилам.

Приёмка: реальный PostgreSQL, повтор и параллельный повтор, конфликт SHA/метаданных, плохая SHA, права/отзыв/смена роли, удаление и физическая очистка, сохранение источника, приватность и retention; CLI против настоящего HTTP API с собственной SIQ-партией и повтором. Проверки не доказывают права на чужие пакеты и не подменяют внешний пилот.

## Запуск оператора

Назначение роли выполняется оператором с доступом к БД: `go run ./cmd/admin role USERNAME admin`. Затем пользователь выпускает токен с `drafts:write` в аккаунте. Сервер должен работать с обычной очередью загрузок и актуальными миграциями.

Пример `manifest.json` рядом с файлом `own.siq`:

```json
{"items":[{"namespace":"agreed-pilot-2026","external_id":"pack-001","file":"own.siq","sha256":"SHA256_АРХИВА_64_СТРОЧНЫХ_HEX_СИМВОЛА","source_url":"https://example.org/packs/001","license":"CC-BY-4.0","attribution":"Имя автора","permission_basis":"Согласование №… / собственная работа"}]}
```

Имя и размер CLI берёт из локального файла. Указывайте реальную лицензию и основание, а не данные из примера. Данные `permission_basis` предназначены для оператора и его выгрузки, не для каталога.

```sh
go run ./cmd/catalogue-import -manifest ./pilot/manifest.json -check
# SI_API_URL: HTTPS origin сервера; HTTP допускается только для loopback.
# SI_API_TOKEN задаётся через защищённое окружение, не аргументом команды.
go run ./cmd/catalogue-import -manifest ./pilot/manifest.json > pilot-report.json
```

CLI принимает только обычные файлы; специальные файлы открываются без ожидания и отклоняются, чтение проверяет отмену между ограниченными блоками. Отмена помечает оставшиеся записи как `not_attempted` и возвращает ненулевой код. Полная проверка всех файлов выполняется до первого HTTP-запроса; архив повторно проверяется перед отправкой. CLI не следует HTTP-редиректам. На запрос — 30 секунд, на партию вместе с предварительной проверкой — час. Повторите ту же команду при неопределённом сетевом исходе: offset и результат находятся на сервере. Код завершения 1 означает неполную партию, подробности — в отчёте; успешные записи повторно не создаются. Партия не является общей транзакцией: уже готовые черновики сохраняются при ошибке следующего файла.

Локальная приёмка реализована в `TestCatalogueCLIPilotAndRepeat`: собственный SIQ → настоящий HTTP/PAT → очередь → приватный черновик с источником → повтор без дубликата → отзыв токена. Права и доступность реальных сторонних пакетов этим тестом не подтверждаются.
