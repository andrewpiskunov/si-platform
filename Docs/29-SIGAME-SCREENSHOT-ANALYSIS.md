# SIGame: настройки и игровая комната по скриншотам

Источник: восемь скриншотов, предоставленных пользователем 21.10.2026. [Оригиналы сохранены в репозитории](references/sigame-2026-10-21/). Номер версии клиента неизвестен. Документ фиксирует наблюдения и предложения для разработки, а не подтверждает полный паритет нашего сервиса с SIGame.

**Главный вывод:** сохраняем узнаваемое синее табло, но проектируем полноценное рабочее место игрока и ведущего. Нужны заметные аватарки, готовность участников, общение и понятное разделение настроек. Выбранный макет «Эфир» — основа оформления; наличие элемента в макете не означает готовую функцию.

## 2. Создание игры: правила комнаты

Сверху видны вкладки «Комната», «Правила», «Время». Внизу — «Создать», в конце списка — «По умолчанию». Содержимое «Комнаты» и «Времени» не предоставлено.

| Группа / настройка | Что видно | Значение для проектирования |
|---|---|---|
| Тип игры | Выбрана «Классическая» | Режим должен сопровождаться кратким объяснением; остальные варианты списка неизвестны |
| Описание классической игры | Перед стартом показываются темы раундов; в таблице игроки выбирают вопросы, основной тип — с кнопкой; в списке тем удаляют темы и играют последнюю, основной тип — для всех со ставкой | Различать механику таблицы и исключения тем, не сводить все раунды к одной сетке |
| Устная игра | Выключена; для ведущего-человека, выбор и ответы голосом, подходит стримам | Отдельно показывать, кто вводит действия в интерфейсе; сама настройка не доказывает встроенный голосовой чат |
| Выбор игроков в устной игре | Галочка есть, контрол выглядит недоступным | Показать зависимость от устной игры; проверить точную семантику перед переносом |
| Управляемая игра | Выключена; продолжение только по «Дальше» | Явное пошаговое управление ведущего |
| Финал: играть все вопросы | Выключено | Отдельная расширенная механика, не тождественная обычному финалу |
| С кнопкой: фальстарты | Включены; нельзя нажимать до конца чтения | Состояние допуска к кнопке должно быть явно видно всем |
| Частичный вывод текста | Выключен, контрол выглядит недоступным; подпись связывает с игрой без фальстартов | Зависимость от режима и серверная синхронизация раскрытия |
| Частичный вывод изображений | Аналогично тексту | Нужны отдельные правила раскрытия, а не только визуальный эффект |
| С кнопкой: штраф | Выбрано «Снимать очки» | Штраф должен быть виден до начала игры |
| Режим нажатия кнопки | Выбрано «Рандом из ранних нажавших» | Нельзя выдавать случайное окно за правило «кто первым нажал»; длительность окна здесь не показана |
| Для себя: штраф | «Нет штрафа (без риска)» | Штрафы задаются по типу вопроса |
| Для себя: множитель | Число 2 | Нужны пределы и правило расчёта; из скриншота они неизвестны |
| Для всех: штраф | «Снимать очки» | Не смешивать с параметром обычного вопроса |
| Для всех со ставкой: допуск | Включены все игроки, даже с нулевым/отрицательным счётом | Допуск и предел ставки — разные правила; предел ставки здесь не указан |
| Ответы ведущему заранее | Включено | Приватная информация ведущего не должна попадать в данные игрока/зрителя |
| Скорость чтения | 20 символов/с, ползунок и числовой ввод | Нужна связь со временем раскрытия/допуском к кнопке; диапазон не виден |
| Апелляции ответов | Включены; подпись «Я прав» и «Я против» | Разделять запрос пересмотра и решение/голосование; процедура здесь не показана |
| Варианты ответа по очереди | Включено | Отдельная последовательность раскрытия вариантов |
| Буквы вариантов ответа | Включено | Согласованное обозначение вариантов для голоса и клавиатуры |
| Предзагрузка медиа | Включена для всех участников в начале раунда | Требует отдельной оценки трафика и преждевременного раскрытия содержания |

## 3. Личные настройки

Вкладки «Общее», «Клавиши», «Тема», «Звуки», закрытие окна и сброс «По умолчанию». Это отдельный интерфейс от создания комнаты. Область хранения и действие на других участников по скриншотам не установлены.

### Общее

| Настройка | Показанное состояние |
|---|---|
| Язык | Русский |
| Звук | Включён |
| Звук приложения | Выключен; отличие от общего звука требует уточнения |
| Мелодия главного меню | Выключена |
| Громкость | Ползунок, точного числа нет |
| Автоматическое скрытие управления | Выключено |
| Комментарии темы и правильный ответ на табло | Включено |
| Кликабельные ответы | Включено; точное действие не видно |
| Видеоаватары | Включено; источник видео и протокол не видны |
| Запись журнала игры | Выключена; место и формат записи не видны |
| События изменения очков в чате | Включено |
| Медиа из внешних источников | Выключено; интерфейс предупреждает об опасности внешнего контента |

Для нашего интерфейса: громкость/звук, видимость управления и отображение событий — личные предпочтения. Они не должны менять общие правила, исход нажатия или момент раскрытия ответа.

### Клавиши

| Роль | Действие | На скриншоте |
|---|---|---|
| Общее | Зацензурить контент | F8 |
| Ведущий | Пауза | F9 |
| Ведущий | Дальше | Стрелка вправо |
| Ведущий | Да | `+` |
| Ведущий | Нет | `-` |
| Игрок | Ответить | Пробел |
| Игрок | Пас | `/` |

Клавиши представлены кнопками; поведение переназначения не показано. Для нас: подписи горячих клавиш рядом с действиями, настройка конфликтов, отсутствие срабатывания при вводе в чат/редактор, учёт роли и этапа игры. Нажатие клавиши проходит тот же серверный контроль, что и кнопка. Смысл и область действия «Зацензурить контент» нужно уточнить.

### Тема

- Табло: цвет текста, цвет фона, выбор шрифта (показан «по умолчанию»).
- Переключатель «Шестиугольное табло вопросов» — выключен.
- Комната: выбор файла фонового изображения и «Удалить».
- Сброс настроек по умолчанию.

В нашем продукте разделять **тему комнаты**, назначаемую ведущим, и **личные изменения отображения**. Личные настройки контраста и отключение декора имеют приоритет для конкретного участника. Пользовательские шрифты и шестиугольная сетка не становятся обязательным P0 только из-за наличия в SIGame.

### Звуки

Для каждого события доступен выбор собственного файла. На скриншотах ни один файл не выбран. Видны 17 событий (повтор «Финальные аплодисменты» на двух скриншотах считается один раз):

| Стадия | События |
|---|---|
| Вход и начало | Главное меню; вход в комнату; раунд; темы раунда |
| Специальные вопросы | Вопрос со ставкой; с секретом; для себя; для всех; со ставкой для всех |
| Финал | Обдумывание в финальном раунде; удаление темы финального раунда |
| Результат ответа | Неправильный ответ; нет ответа |
| Реакции | Большие, финальные и малые аплодисменты |
| Время | Таймаут раунда |

Есть общий сброс. Форматы, длительность, размер, хранение и распространение файлов не видны. Для будущих звуковых наборов нужны предпрослушивание, общий mute, пределы файлов и воспроизведение по идентификатору события без дубля после reconnect; учитывать ограничения автозапуска браузера. Переносить звуковые файлы SIGame из скриншотов невозможно и не требуется.

## 4. Комната и состояние ожидания

Скриншот 8 показывает **лобби перед стартом**, а не активный вопрос.

| Зона | Наблюдение | Вывод для «Эфира» |
|---|---|---|
| Центр | Большое поле с инструкцией: нажимать после появления рамки, игра начнётся после готовности всех | Отдельные состояния «ждём участников», «чтение», «кнопка открыта», «ответ», «пауза», «результат»; текст и индикатор вместо одного цвета |
| Под полем | «Ссылка для входа», «ПИН-код», широкая зелёная «Готов к игре» | Приглашение и готовность — самостоятельные действия; не подменять приглашение настройками |
| Слева | Крупная карточка с портретом, именем «Леонардо да Винчи», зелёным значком и меню; предположительно ведущий | Отдельная зона ведущего; роль подтвердить по рабочему клиенту |
| Снизу | Три места игроков; одно занято, видны аватар, имя «123», счёт 0, звезда и меню; два места пусты | Аватар — заметная часть карточки, не маленькая декоративная точка; показывать свободные места. Значение звезды по скриншоту неизвестно |
| Справа | Панель чата, поле сообщения, кнопка с эмодзи; сверху значки чата, людей, информации | Разделить «Чат», «Участники», «О комнате»; сохранять читаемое табло при открытой панели |
| Верхняя/нижняя панели | Значки выхода, глаза, разворота, шестерёнки, аватара; снизу человек с плюсом, пауза и запуск | Назначение без подписей неоднозначно. В нашем интерфейсе нужны подписи/tooltip, доступные имена и единая SVG-система |
| Слева сверху | Баннер поддержки развития/хостинга | Это наблюдение о монетизации, не требование добавить донат в игровую комнату |

Три места на снимке не ограничивают наш сервис: **до 12 игроков плюс ведущий**. Нужно проверить компоновки для 1, 3, 6 и 12 игроков. На десктопе можно использовать боковую панель или нижнюю ленту; на телефоне — отдельную вкладку участников/чата, сохранив доступность игровой кнопки. Крупные аватары не должны вытеснять вопрос.

## 6. Предложение для следующих экранов

1. **Создание комнаты:** основные поля и понятный пресет, затем вкладки «Правила» и «Время». Расширенные параметры сгруппированы по типу вопроса; зависимые контролы объясняют, почему недоступны. Закреплённая кнопка создания не перекрывает поля.
2. **Лобби:** выбранный пакет, ведущий, приглашение, места до 12 игроков, готовность и причина, почему ещё нельзя начать. Настройки комнаты доступны ведущему; остальные видят сводку.
3. **Игра:** большое табло, заметные аватарки и счёт, текущий выбирающий/отвечающий, явный допуск к кнопке; чат раскрывается отдельно. Состояния готовности, отключения и ответа визуально различаются.
4. **Личные настройки:** «Общее», «Клавиши», «Оформление», «Звуки». Сброс действует на текущий раздел, а глобальный сброс обозначен отдельно. Не смешивать личные предпочтения с общими правилами.
5. **Системные ограничения:** смена правил не влияет задним числом на начатый вопрос; клиентская готовность/горячая клавиша не заменяет проверку сервера; общие изменения видны участникам после подтверждения.

## 7. Что ещё проверить по живому SIGame

- Полное содержимое «Комнаты» и «Времени», альтернативы выпадающих списков и фактические значения после сброса.
- Связь устного режима, управляемой игры, частичного раскрытия и фальстартов; автоматические действия при истечении времени.
- Смысл кликабельных ответов, цензуры, значков глаза/звезды и разграничение ролей.
- Кто и когда получает ответ ведущего, варианты ответа и файлы при предзагрузке.
- Реальная процедура апелляции и ставки для игроков с нулевым/отрицательным счётом.
- Старт при неготовом/отключившемся игроке, смена ведущего, переподключение; активный вопрос и финал.
- Хранение личных настроек, загрузка аватаров, устройство видеоаватаров и звуковых наборов.

Для этих пунктов нужны наблюдения рабочего клиента или конкретной версии исходников. Предоставленные изображения не подтверждают поведение.
