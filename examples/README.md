# Демонстрационные материалы

`Demo()` в `demo.go` создаёт девять оригинальных текстовых вопросов для проверки игрового прохода. Контент этого демонстрационного пакета разрешено использовать, изменять и распространять на условиях **CC0-1.0**. Он не скопирован из SI Browser.

Создание архива: `go run ./cmd/siq sample /tmp/first-game.siq`.

Фикстуры совместимости в `internal/siq/*_test.go` также написаны специально для проекта. Они проверяют формат и пограничные случаи; это синтетический корпус, а не репрезентативная выборка пакетов сообщества.
