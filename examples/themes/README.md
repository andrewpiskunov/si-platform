# Пример пользовательской темы

«Морская карта» — небольшой пример формата v1: тёмная контрастная палитра и оригинальный компас. `theme.json` — редактируемый исходный манифест. `example.go` рисует компас 128 × 128 пикселей и упаковывает манифест вместе с `assets/compass.png`; сторонних изображений и сетевых запросов нет. Манифест и иллюстрация распространяются на условиях **CC0-1.0**.

Из корня репозитория создайте или обновите опубликованные файлы:

```sh
go run ./cmd/theme-example
```

Команда пишет `web/static/themes/example.zip` и `web/static/themes/guide.html`. Для другой папки используйте `go run ./cmd/theme-example -out /tmp/theme-example`. `guide.html` в этой папке — исходник самостоятельной русской инструкции; опубликованная копия должна совпадать с ним.

Порядок записей ZIP, права и время фиксированы; PNG строится из неизменной геометрии. При одинаковой версии Go повторная генерация даёт одинаковые байты. Тест сравнивает результат со скачиваемым архивом и инструкцией, а также проверяет совпадение манифеста с исходником.

```sh
go test ./examples/themes
# С настроенными FFmpeg, FFprobe, bubblewrap и prlimit:
MEDIA_INTEGRATION=1 go test -race ./examples/themes
```

При необходимости укажите абсолютные пути к доверенным исполняемым файлам в `MEDIA_FFMPEG` и `MEDIA_FFPROBE`; иначе они ищутся в `PATH`. Интеграционный тест пропускает пример через настоящий парсер темы и изолированный процесс подготовки, проверяет оба PNG, исходный хеш, размеры и общий небольшой объём. Без `MEDIA_INTEGRATION=1` проверка реального процессора явно пропускается; разбор архива и проверка опубликованных файлов выполняются всегда.

Пользовательские ссылки: [скачать ZIP](/themes/example.zip) и [инструкция](/themes/guide.html). Формат и правила хранения описаны в [Docs/16-CUSTOM-THEMES.md](../../Docs/16-CUSTOM-THEMES.md).
