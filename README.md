# SI Platform — рабочее название

Проект единой веб-платформы для проведения «Своей игры» с темами оформления, создания пакетов, работы с ИИ и публикации в каталоге.

Сейчас в репозитории — аналитика и проектные предложения для ревью. Приложение ещё не реализовано.

**Начните с [продуктового плана](Docs/00-PRODUCT-PLAN.md)**: он содержит основную концепцию, границы первой версии и решения, которые нужно обсудить.

Дата исследования: **20 октября 2026 года**. Рекомендации и числовые цели — предложения для обсуждения; результаты нагрузочных испытаний отсутствуют.

Для ревью достаточно написать номер решения `D-01` или требования `FR-01` и желаемую правку. Подтверждены открытый сервис для сообщества, до 12 игроков, бэкенд на Go, готовые и загружаемые темы оформления. Название, бюджет, фронтенд и регион размещения пока не утверждены.
