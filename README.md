# SI Platform — рабочее название

Проект единой веб-платформы для проведения «Своей игры» с темами оформления, создания пакетов, работы с ИИ и публикации в каталоге.

В репозитории — Go API, PostgreSQL, браузерный интерфейс SvelteKit, комнаты до 12 игроков, редактор и каталог пакетов SIQ. Новое игровое ядро поддерживает текстовые спецвопросы, финал, ставки, таймеры и восстановление. Полный MVP ещё в разработке: медиа, собственные темы оформления, ИИ/MCP и эксплуатационные испытания перечислены в [статусе](Docs/11-IMPLEMENTATION-STATUS.md).

**Запуск:** [браузерная игра и мастерская](Docs/13-WEB-AND-AUTHORING.md). Для локального запуска нужны Go, PostgreSQL и Node; веб открывается на **http://localhost:5173**. `go run ./cmd/demo` проверяет 12 одновременных участников через настоящий HTTP/WS API.

Docker Compose подготовлен для самостоятельного размещения; его запуск в этой среде пока не проверен.

**Начните с [продуктового плана](Docs/00-PRODUCT-PLAN.md)**: он содержит основную концепцию, границы первой версии и решения, которые нужно обсудить.
