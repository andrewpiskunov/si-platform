# SI Platform — рабочее название

Проект единой веб-платформы для проведения «Своей игры», создания пакетов, работы с ИИ и публикации в каталоге.

Сейчас в репозитории — аналитика и проектные предложения для ревью. Приложение ещё не реализовано.

**Начните с [продуктового плана](Docs/00-PRODUCT-PLAN.md)**: он содержит основную концепцию, границы первой версии и решения, которые нужно обсудить.

| Документ | Что внутри |
|---|---|
| [00 — Продуктовый план](Docs/00-PRODUCT-PLAN.md) | Предложение, бизнес-требования, MVP, экономика, вопросы |
| [01 — Исследование](Docs/01-RESEARCH.md) | SIGame, SIQuester, SI Browser, совместимость и перенос каталога |
| [02 — Требования](Docs/02-REQUIREMENTS.md) | Функции, настройки игры, измеримые критерии качества |
| [03 — Архитектура](Docs/03-ARCHITECTURE.md) | Стек, WebSocket, синхронизация, медиа, ИИ/MCP и нагрузка |
| [04 — План работ](Docs/04-ROADMAP.md) | Дальнейшая аналитика, этапы и критерии перехода |
| [05 — Источники](Docs/05-SOURCES.md) | Первичные источники и границы исследования |

Дата исследования: **20 октября 2026 года**. Рекомендации и числовые цели — предложения для обсуждения; результаты нагрузочных испытаний отсутствуют.

Для ревью достаточно написать номер решения `D-01` или требования `FR-01` и желаемую правку. Аудитория подтверждена: открытый сервис для сообщества. Название и бюджет пока не утверждены.
