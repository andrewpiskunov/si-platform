# SI Platform — рабочее название

Проект единой веб-платформы для проведения «Своей игры» с темами оформления, создания пакетов, работы с ИИ и публикации в каталоге.

В репозитории — аналитика и первый работающий Go-прототип игрового ядра: комнаты, WebSocket, до 12 игроков, решения ведущего, PostgreSQL, защита от повторов и восстановление. Графический интерфейс и остальные продуктовые блоки ещё предстоит реализовать.

**Запуск и протокол:** [игровое ядро](Docs/10-GAME-CORE.md).

```sh
cp .env.example .env
docker compose up --build -d
docker compose run --rm --no-deps --entrypoint /app/demo api -url http://api:8080
```

Демо проверяет игру с 12 участниками через настоящий HTTP/WS API. API слушает `http://127.0.0.1:8080`; игровой страницы пока нет. Вариант без Docker, тесты и команды разработки описаны в инструкции.
